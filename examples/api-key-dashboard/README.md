# Developer Team API Key Management Dashboard

Standalone React + Tailwind demo generated from this repository's UI/UX datasets.

Design inputs used:
- `data/typography.csv`: Minimal Swiss — Inter, weight-led hierarchy for dashboards/admin tools.
- `data/styles.csv`: minimal, functional, spacious, high-contrast dashboard treatment.
- `data/stacks/shadcn.csv`: semantic theme variables, accessible dialogs/actions, table semantics, individual component composition.
- `data/landing.csv`: responsive sidebar/mobile navigation patterns and thin divider-led content organization.

Run locally:

```bash
npm install
npm run dev
```

This is a visual/interaction demo only. Displayed API keys are synthetic and no credential operations reach a backend.
